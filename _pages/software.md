## Research code & models

- [StructGAN](https://github.com/wenjie-liao/StructGAN_v1): generative adversarial networks for shear-wall building design.
- [StructGAN-PHY](https://github.com/wenjie-liao/StructGAN-PHY): structural design generation coupled with physical analysis.
- [StructGAN-Hybrid](https://github.com/wenjie-liao/StructGAN-Hybrid): ETABS model examples accompanying physics- and rule-guided base-isolation design research.

See the linked repositories for available code and model files. Browse [all public repositories](https://github.com/wenjie-liao).
